<h1>First Response</h1>
<p>Status: in development; core loop playable</p>
<p>An emergency triage and treatment game where you race against the clock to remove conditions, cure ailments and patch-up injuries.</p>
<p>Points are awarded for speed and following the correct procedure: DrsABC gamified!</p>
<p>Inspired by restaurant / chef games, it is played in an arcade format with simple controls and an art style that allows anyone to learn and enjoy.</p>
